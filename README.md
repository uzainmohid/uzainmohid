### 🧭 About Me

I'm a BCA Data Science student and AI builder who designs and ships **AI-powered systems and products that solve real business problems** — not just prototypes. My approach is project-first: I build, debug, and iterate on real implementations rather than stopping at theory.

### 🧠 What I'm Building

**⚖️ LegalRAG-AI** — A legal-focused RAG system for retrieving, processing, and generating contextual legal information using LLM pipelines and vector retrieval.

**📄 QuanDoc-AI** — An AI-powered document interaction system for intelligent querying, document understanding, and workflow automation.

**🔎 ResearchOS** *(Hoardy AI Internship)* — An AI-powered Wikipedia Research Assistant agent that takes a user question, retrieves and extracts source content via the Hermes CLI, and generates structured research summaries — integrated as a live Discord bot powered by Google Gemini and DuckDuckGo search.

Through these, I've worked hands-on with vector databases, embeddings, retrieval pipelines, prompt engineering, context optimization, agent orchestration, API integrations, and debugging real AI system behavior.
